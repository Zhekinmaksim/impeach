    Contract deployment on Bradbury

    Check from a terminal

    python3 cli/impeach.py check --text "…the item…"
python3 cli/impeach.py check <sha256> --address $CONTRACT
python3 cli/impeach.py recompute web/case.json

    The first two exit with status 1 when the item is spent, so they can gate a CI job. The third rebuilds every verdict on this page from the published probes.

    What this does not show

    A gap is evidence, not proof: every model drops a little on rewritten questions, and the threshold is a convention. The raw counts are published so a reader can disagree with it. Only subjects that answer a public endpoint can be tried.
